Web Basics: your first webpage

Every website is just text with tags. Let’s build one from scratch.

Every page has a skeleton

HTML uses tags in angle brackets. A tag that opens must also close. Here’s the smallest real page:

<!doctype html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello!</h1>
  </body>
</html>
  1. 2

Add a heading and a paragraph

Put content inside <body>. Use <h1> for a title and <p> for a paragraph.

<body>
  <h1>Rexdale Youth Night</h1>
  <p>Come build, belong, and grow.</p>
</body>

Try it yourself

Change the heading, then run it.

<h1>Change me</h1>
<p>Write your own line here.</p>
