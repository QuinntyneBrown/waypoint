Messages and error codes

Every message Waypoint can put in front of you comes from one of three places: a validation rule that checked what you typed, a named error that maps to a specific HTTP status, or an unexpected failure. This page lists all three, verbatim, with the status code behind each and what to do next. Look up the words you can see on screen.

Everyone W-UG-15

How Waypoint reports a problem

Waypoint never shows you a raw error. Every failure that reaches the interface is a small JSON body with a title field, and the interface shows that title to you as the message text. If you are reading this page because of something you saw on screen, the words you saw are the title.

The ordinary shape

Most failures carry nothing but a title. That title is the whole explanation. 

{
  "title": "This youth is not assigned to you."
}

A validation failure

When something you typed does not pass a rule, the title is always exactly Validation failed and the body carries an errors list — one entry per field that failed, naming the field and the message for it. The interface puts each message under its own field, so you rarely see the list itself. 

{
  "title": "Validation failed",
  "errors": [
    {
      "propertyName": "GuardianEmail",
      "errorMessage": "A valid guardian email is required for applicants under 18."
    },
    { "propertyName": "Age", "errorMessage": "Applicants must be aged 12–18 inclusive." }
  ]
}

Every message in that list is fixed text written into the product. All of them are catalogued in Validation messages, by area below. A validation failure is always 400 and it never means anything is broken — it means one specific field needs changing.

An unexpected failure

If Waypoint hits something it did not plan for, the response is a 500 with a fixed title and a correlationId. That identifier is the single most useful thing you can pass to whoever supports your installation: it is written into the server log alongside the real cause. 

{
  "title": "An unexpected error occurred.",
  "correlationId": "0af7651916cd43dd8448eb211c80319c"
}

A 500 never shows you a stack trace

The body carries the title and the correlation id and nothing else. No file names, no line numbers, no internal exception text. That is deliberate: the detail goes to the server log, where only your operations team can read it. If someone shows you a Waypoint screen with a stack trace on it, it is not this release.

Every response Waypoint sends — success or failure — carries an X-Correlation-ID header. If you send your own value in that header it is reused, as long as it is 128 characters or fewer and contains only letters, digits, and - _ . characters. Anything else is replaced with a generated one.

Every status you can meet

These are the only statuses a person using Waypoint will ever be shown. The status decides how the interface reacts — a 401 sends you to the sign-in screen, a 403 to the Error 403 page, a 503 to the maintenance page — so knowing the status tells you what kind of problem you have.

Status Meaning When it happens What to do
400 Bad request A validation rule failed, sign-in credentials were wrong, the email is already registered, or no guardian email is linked to the account Fix the named field and try again. Nothing was saved.
401 Not signed in You have no session, or your session is no longer valid — it expired, was signed out elsewhere, or your refresh token was rotated Sign in again. You land on You’ve been signed out and your unsaved work is restored afterwards.
403 Not allowed Your role does not hold the permission, the record is outside your scope, guardian participation consent is missing, media consent is missing, or the account is deactivated Read the message — it says which of those it is. Every 403 is written to the audit log.
404 Not found The thing you asked for does not exist, or has been removed Go back and reload the list you came from; the record may have been deleted since you last looked.
409 Conflict The action is legal in general but not from the current state — a decision is already final, someone else changed the record first, or a rule of the lifecycle blocks it Reload and look at the current state. The message names the exact rule; see Lifecycles and the evidence they leave.
410 Gone A one-time link has been used, revoked, or has expired — an invitation, a password reset, or a guardian consent link Ask for a new link. The old one can never be revived.
423 Locked Five failed sign-in attempts on the same account Wait about 15 minutes, or reset your password to unlock immediately.
429 Too many requests More than 20 requests in 60 seconds from your network address to sign-in, invitations, or password reset Wait. The response carries a Retry-After header saying how many seconds.
500 Unexpected error Something failed that Waypoint did not anticipate Try again in a moment. If it repeats, quote the correlationId from the response.
503 Maintenance Maintenance mode is switched on; everything except the health check is turned away Wait and retry. The response asks you to come back in 120 seconds.

The two statuses with their own body shape

A 429 and a 503 do not look like the others. Both add a Retry-After header, and the 503 adds a second line of explanation. 

HTTP 503  Retry-After: 120

{
  "title": "Waypoint is down for scheduled maintenance.",
  "detail": "Nothing you've done is lost. Please check again shortly.",
  "retryAfterSeconds": 120
}

In the portal a 503 becomes the maintenance page: Scheduled maintenance / We’ll be right back / Waypoint is down for a short bit of maintenance. Nothing you’ve done is lost — please check again shortly.

The fixed messages, word for word

These messages are written into the product and never vary, except for the lockout message which fills in the number of minutes. If you can see one of these on screen, this table tells you exactly what happened.

Message Status What it means, and what to do
Invalid email or password. 400 Sign-in failed. It says nothing about which half was wrong, and it is the same message whether or not the email belongs to an account. Check both, then use Forgot password if you are unsure.
This account is temporarily locked. Try again in about {n} minutes, or reset your password. 423 Five failed attempts in a row locked the account. {n} is filled in with the real number of minutes, normally 15. A password reset clears the lock straight away.
This account is inactive. Please contact your program director. 403 The account has been deactivated by an administrator. The password is correct; the account is not usable. Only an administrator can reactivate it — unless the account was removed, in which case it cannot be brought back at all.
Your session is no longer valid. Please sign in again. 401 Your refresh token was unknown, expired, or reused after it had already been rotated. Reuse is treated as a possible theft, so the whole session family is dropped. Sign in again.
This invitation is no longer valid. Please request a new invite. 410 The invitation link has expired (they last 14 days), was revoked, was already accepted, or does not exist. Invitations are single use. Ask whoever invited you to resend.
This reset link is invalid or has expired. 410 The password-reset link is expired, already used, or unknown. Start again from Forgot password.
This consent link has expired or has already been used. Ask the youth to send a new link. 410 A guardian opened a consent link that is spent. The youth can send a fresh one from their consent screen.
Guardian participation consent is required. 403 A youth tried to reach lessons, quizzes, submissions, reflections, or their journey without a valid guardian participation consent. The response also carries X-Waypoint-State: consent-required, and the portal redirects to A guardian needs to sign off.
Guardian consent for individual photos or video is required. 403 Someone tried to use a youth's individual photo or video without that specific media permission. Participation consent alone is not enough — media consent is separate and granular. Carries X-Waypoint-State: media-consent-required.
No guardian email is linked to this account. Please contact the program team. 400 A youth asked Waypoint to send a consent link, but no guardian address is on record. An administrator has to add one first.
You do not have access to this resource. 403 The general refusal, used when no more specific message applies. Most scope refusals say something more precise — see Roles and permissions.
Not found. 404 The general "does not exist" message. Most lookups say what was missing instead — Cohort not found., Submission not found., Person not found., and so on.
The request conflicts with the current state. 409 The general conflict message. In practice you almost always get a specific one instead, such as This application already has a final decision.
Too many requests. Please try again later. 429 You hit the rate limit on the sign-in, invitation, or password-reset surface. Wait for the number of seconds in the Retry-After header.

Two more you may meet on the way in

Email '…' is already registered.

400. Registration was attempted with an address that already has an account. Sign in instead, or reset the password.

An unexpected error occurred.

500. Quote the correlationId that came with it.

The X-Waypoint-State header

Two refusals are not really about permission at all — they are about consent, and the fix is a form rather than a different account. So that the portal can tell them apart from an ordinary refusal, those two responses add a header called X-Waypoint-State. It has exactly two values and appears on nothing else.

Value Sent with What the portal does
consent-required 403 Guardian participation consent is required. Sends the youth to A guardian needs to sign off, which offers Notify my guardian, My guardian can sign now and Sign out — rather than the generic Error 403 page.
media-consent-required 403 Guardian consent for individual photos or video is required. Explains that a media permission is missing rather than implying the user is in the wrong place.

The header is exposed across origins on purpose, so the portal can read it even though it is served from a different address than the API.

Sign-in and account safety

The sign-in surface behaves in a few ways that look unhelpful until you know why. They are all deliberate.

Unknown email and wrong password fail identically

Both produce exactly Invalid email or password. with a 400. Waypoint will not tell you whether an address has an account, because that would let anyone test a list of addresses to find out who is in the program. If you are unsure which account you have, use Forgot password — it also gives the same answer whether or not the address exists, and sends mail only if it does.

Five failed attempts locks the account

The password rule

One rule, applied identically wherever a password is set — when you accept an invitation, when you reset a forgotten password, and when you change your password in settings:

Password must be at least 8 characters and include at least one letter and one number.

There is no maximum complexity rule, no forced symbol, no expiry, and no password history. Confirmation mismatches give Passwords do not match. on the reset form and The confirmation password does not match the new password. on the change-password form. Getting your current password wrong when changing it gives The current password is incorrect. as a 403.

The rate limit

Waypoint allows 20 requests per 60 seconds from any one network address across three surfaces:

  • /api/auth — sign in, register, refresh, sign out
  • /api/invitations — creating, accepting, resending and revoking invitations
  • the administrator's send password reset action on a person's record

Going over gives a 429 with Too many requests. Please try again later. and a Retry-After header. The limit is counted per network address, not per account — so on a shared connection, one person hammering sign-in can rate-limit everyone else in the room. Wait the minute out.

Preview limitation

Idle sign-out gives no warning. After 30 minutes of inactivity you are signed out with no countdown and no "are you still there?" prompt. Waypoint captures what you had typed into a form first and restores it after you sign back in, but there is nothing on screen to tell you the clock is running.

Validation messages, by area

Every message below is a fixed string checked before anything is saved. All of them arrive as 400 with the title Validation failed, attached to the field they belong to. Nothing is written when one of these fires.

Fields also have plain length and required rules that produce standard messages naming the field — those are not listed individually; the limits are given in the What to do column where they matter.
