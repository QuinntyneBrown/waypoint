# Waypoint — User Journeys

Ordered from most to least essential to the product's impact and usefulness.

| # | Journey | Description |
|---|---|---|
| 1 | Complete lessons | Youth works through gated lessons, including coding tracks. |
| 2 | Mentor dashboard | Mentor views their roster and youth details. |
| 3 | Sign in | User signs in with email and password. |
| 4 | Accept invitation | Invited user activates account and sets password. |
| 5 | Give guardian consent | Guardian grants or withdraws consent for a minor. |
| 6 | Author curriculum | Admin builds tracks, modules and lessons. |
| 7 | Manage cohorts | Admin creates cohorts and assigns mentors to youth. |
| 8 | Apply or refer | Youth, guardian or referrer submits an application. |
| 9 | Review and place | Admin reviews applications and places youth into cohorts. |
| 10 | Submit assignments | Youth submits work and tracks the review outcome. |
| 11 | Grade and assess | Mentor grades submissions, approves quizzes and assesses competencies. |
| 12 | Take quizzes | Youth attempts quizzes and views scores and results. |
| 13 | Author quizzes and assignments | Admin creates quizzes, assignments and attempt rules. |
| 14 | View journey and progress | Youth views badges, streaks and overall progress. |
| 15 | Check in | Mentor logs check-ins with assigned youth. |
| 16 | Flag at-risk youth | Mentor raises and tracks at-risk concerns. |
| 17 | Schedule sessions and RSVP | Staff schedule sessions and participants RSVP. |
| 18 | Take attendance | Staff record attendance, including offline. |
| 19 | Manage people | Admin manages user accounts, roles and their lifecycle. |
| 20 | Assign work | Mentor assigns specific tasks to youth. |
| 21 | Announce and message | Users send announcements and direct messages. |
| 22 | Receive notifications | Users get near-real-time alerts for relevant activity. |
| 23 | Guardian portal | Guardian views their child's progress, schedule and consents. |
| 24 | Reset password | User recovers access through an emailed reset link. |
| 25 | Author badges and progression | Admin defines badges, award rules and progression framework. |
| 26 | Write reflections | Youth records personal reflections on learning. |
| 27 | First-run onboarding | New user completes guided setup after first sign-in. |
| 28 | Explore public site | Visitor browses programs, open cohorts and donates. |
| 29 | Report, export and import | Admin runs reports and moves data in and out. |
| 30 | Volunteer portal | Volunteer views their assignments and sessions. |
| 31 | Configure organization | Admin edits organization-wide settings. |
| 32 | Manage personal settings | User updates profile, notifications and theme. |
