# L2 — Volunteer Portal (VOLUNTEER)

Each L2 traces to an L1 in `volunteer-portal/L1.md`.

## L2-VOLUNTEER-001: Volunteer today and attendance
**Traces to:** L1-VOLUNTEER-001

Volunteers must see only their assigned session and take Present/Absent attendance.

**Acceptance Criteria:**
1. Given a volunteer, when the volunteer opens their portal, then only today's assigned session (logistics + roster count) is shown, with no youth progress/records.
2. Given the volunteer, when the volunteer opens the attendance function, then each youth shows their name only, with a Present/Absent control and "all present" bulk action, and no at-risk flag or other safeguarding data is exposed.
3. Given a volunteer saves attendance, when confirmed, then records persist (offline-capable — see L2-NFR-004) and no additional youth data is exposed.
4. Given a volunteer requests any out-of-scope resource, when attempted, then it is denied with 403 (see L2-AUTH-010, L2-PLATFORM-006).

## L2-VOLUNTEER-002: Volunteer schedule
**Traces to:** L1-VOLUNTEER-001

Volunteers must view their upcoming schedule.

**Acceptance Criteria:**
1. Given a volunteer, when the schedule loads, then upcoming assigned sessions with status are shown.
2. Given no assigned sessions, when the schedule loads, then an empty state is shown.
