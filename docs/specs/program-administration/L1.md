# L1 — Program Administration (ADMIN)

High-level requirements for managing people, cohorts, mentor assignment, and organization settings.

## L1-ADMIN-001: People directory & account lifecycle
The system must provide a directory of everyone in the program (youth, staff, guardians, volunteers) with search and filters, individual records, role changes, and reversible deactivation vs. irreversible removal that preserves progress records for reporting.

Note: bulk data import of people and roster data is provided by REPORT-004 (cross-reference, not a separate program-administration requirement).

## L1-ADMIN-002: Cohort management
The system must let admins create and manage cohorts (name, track, term dates, meeting location, lead mentor), add/remove youth, view cohort membership and health, and view an org-wide "every youth × every module" progress board that replaces the spreadsheet.

## L1-ADMIN-003: Mentor–youth assignment
The system must let admins assign mentors to youth and to cohorts (including a lead mentor and supporting mentors), surface each mentor's caseload, and warn on load imbalance.

## L1-ADMIN-004: Organization settings
The system must let the director configure org-level settings — organization identity (including a configurable organization logo and display name), terms/cohort cycles, per-track enable/disable, the guardian consent statement, and re-consent-per-term and media-consent policies. The colour palette is fixed platform-wide and is not editable per organization.
