# L1 — Public Site (PUB)

High-level requirements for the public, unauthenticated marketing website.

## L1-PUB-001: Public marketing website
The system must serve a public, unauthenticated marketing site (landing, about, programs, get-involved, contact, privacy, application confirmation) that explains the program, its tracks, cohorts, mentorship model, and impact, and funnels visitors toward applying, volunteering, donating, or contacting the team.
