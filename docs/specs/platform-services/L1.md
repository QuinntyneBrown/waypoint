# L1 — Platform Services (PLATFORM)

High-level requirements for cross-cutting product capabilities available to multiple roles.

## L1-PLATFORM-002: User settings
The system must let each user manage their profile (name, email, photo, password), notification preferences (per event, delivered as in-app notifications with email as an optional channel), and display/accessibility preferences (text size, high contrast, reduced motion, underline links, reading font, light/dark theme), and access help/support.

## L1-PLATFORM-003: System states & error handling
The system must present clear, recoverable states for error and edge conditions — forbidden (403), not found (404), server error (500), maintenance (503), offline, session expired, consent required, invite expired, no cohort yet, and account deactivated — each with an appropriate message and recovery action.
