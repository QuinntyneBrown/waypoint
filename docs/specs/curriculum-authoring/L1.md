# L1 — Curriculum Authoring (CURRIC)

High-level requirements for authoring the curriculum, assessments, badges, and the progression framework.

## L1-CURRIC-001: Tracks, modules, and lessons authoring
The system must let authorized staff author a curriculum hierarchy of Tracks → Modules → Lessons with ordering, prerequisites, scripture anchors, learning objectives, teaching content, media, reflection prompts, and mentor-only leader guides, governed by a Draft → In review → Published lifecycle scoped to assigned cohorts.

## L1-CURRIC-002: Quiz authoring
The system must let staff build quizzes attached to modules/lessons, defining questions of multiple types, correct answers, pass mark, attempts allowed, feedback mode, shuffle, and whether passing is required to complete the module.

## L1-CURRIC-003: Assignment authoring
The system must let staff define assignments with a task description, permitted submission types (text/photo/link/file), a points-based rubric, due date, grace period, late-submission policy, and optional mentor-approval-to-complete gate.

## L1-CURRIC-004: Badge authoring & awarding
The system must let staff define badges (name, icon, description) with either automatic award rules (module/lesson completed, quiz passed, attendance streak, assignment approved) or manual mentor award, optionally mapped to a competency, and award/track them per youth.

## L1-CURRIC-005: Progression framework authoring
The system must let staff define an ordered progression framework of stages, each containing named competencies, that describes the youth journey from newcomer to leader and underpins competency assessment and reporting.
