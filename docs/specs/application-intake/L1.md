# L1 — Application Intake (INTAKE)

High-level requirements for the youth application/referral pipeline, from submission through review and cohort placement.

## L1-INTAKE-001: Application & referral submission
The system must let a prospective youth, a parent/guardian, or a referring leader submit an application to join Waypoint, capturing eligibility, guardian, neighbourhood, track interest, motivation, and consent/privacy acknowledgement.

## L1-INTAKE-002: Application review & cohort placement
The system must route each submitted application into an admin review pipeline that captures a decision, and on approval places the applicant into a cohort with an assigned mentor (creating the youth account/enrollment), or declines with an optional note.
