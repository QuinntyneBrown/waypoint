# L1 — Multi-Tenancy (TENANCY)

High-level requirements for hosting many organizations on one shared Waypoint deployment, each with its own isolated data.

## L1-TENANCY-001: Organization data isolation
The system must host multiple organizations (tenants) on a shared deployment and database, where every organization-owned record belongs to exactly one organization and no user can see, change, or infer another organization's data.

## L1-TENANCY-002: Organization provisioning and lifecycle
The system must let a Platform Operator create, suspend, and reactivate organizations and invite each organization's first Program Administrator, without granting the Platform Operator access to any organization's youth, guardian, or program data.

## L1-TENANCY-003: Migration of existing data
The system must move all data that exists before multi-tenancy is introduced into a single default organization, with no loss of records and no change in behaviour for its existing users.
