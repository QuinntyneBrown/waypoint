# L1 — Reporting & Data (REPORT)

High-level requirements for reporting, export, and data migration.

## L1-REPORT-001: Reporting
The system must provide reports and analytics for staff — org dashboard KPIs, progression over time, completion by module, weekly engagement, and detailed individual-youth, cohort, attendance, and staff-activity reports — filterable by date range, cohort, track, and mentor.

## L1-REPORT-003: Data export
The system must export reports and the progress board in CSV and PDF formats, respecting the currently applied filters and the requester's authorization scope.

## L1-REPORT-004: Data import / migration
The system must let admins migrate roster data by uploading a CSV, mapping the uploaded columns to system fields, previewing per-row validation (ready / missing consent / duplicate), and importing only the valid rows.
