Dialog

A modal window for a focused decision or short form: invite a user, confirm removal, review an application.

WCAG 2.2 AALight + dark

Overview

Use a dialog when the person must respond before continuing. For longer edits, use a page; for supplementary detail, a drawer.

Anatomy

  1. Scrim--color-bg-backdrop.
  2. PanelRaised surface, 14px radius, --shadow-4, 480px wide.
  3. HeaderTitle, optional subtitle, close button.
  4. BodyContent.
  5. FooterActions, primary last.

Sizes

Set with .ph-modal--sm / .ph-modal--lg.

Small 400px (confirmations), medium 480px (default), large 720px (application review).
HTML
<p>Set with <code>.ph-modal--sm</code> / <code>.ph-modal--lg</code>.</p>

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

VariantDefaultBusy
Footer

Both themes

Invalid: field errors appear inside the body; failed: a danger alert appears at the top of the body and the dialog stays open.

Responsive behaviour

  • Below 640px the dialog becomes a bottom sheet: full width, top corners rounded, footer stacked with the primary on top.

Theming

Panel --color-bg-surface-raised, which is lighter than the surface in dark; scrim darker in dark.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

WAI-ARIA APG Dialog (Modal): role="dialog" (or alertdialog for confirmations), aria-modal="true", labelled by its title. Prefer the native <dialog> with showModal().

Keyboard

KeyAction
Tab / Shift+TabCycles within the dialog only.
EscCloses (same as Cancel).
EnterSubmits when focus is in a field.

Focus

On open, focus the first field (or the least destructive button in a confirmation). On close, return focus to the trigger. The page behind is inert.

Labelling

aria-labelledby title, aria-describedby subtitle/body.

Content

  • Title asks or states: "Remove Maya from Spring cohort?".
  • Buttons repeat the verb: "Remove from cohort" / "Keep Maya".
