Tooltip

A short text label shown on hover and focus, mostly for icon buttons.

Overview

Tooltips name or briefly explain a control. They never hold links or buttons; use a popover or inline text for that.

Anatomy

  1. BubbleInverse surface, 12px text, 6px radius.
  2. Shortcut (optional)Mono kbd.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Responsive behaviour

  • On touch, tooltips appear on long-press; never rely on them for essential info.

Theming

Inverse surface flips with theme.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

role="tooltip" referenced by aria-describedby (or the label itself is aria-label). Appears on hover and focus after 300ms; hides instantly; stays while hovered (1.4.13).

Keyboard

KeyAction
EscDismisses without moving focus.

Focus

Shown when the trigger has focus.

Do not repeat the accessible name in a description.
