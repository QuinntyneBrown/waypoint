Overview

Lesson steps list a module's lessons with their status. For a history of events use a timeline.

Anatomy

  1. Number / status32px circle: lime when done, ink when current.
  2. BodyTitle and status line.
  3. RowCard-like with hairline border.

Variants

See anatomy.

Vertical list (default); application stages use the timeline.
HTML
<p class="w-muted">See anatomy.</p>

Sizes

One size.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Status is also written as text ("Completed", "Locked"), not shown only by colour or icon.

Responsive behaviour

  • Full width at all sizes.

Theming

Done: --color-brand. Current: --color-accent.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

<ol>; current step aria-current="step"; locked steps are not links.
