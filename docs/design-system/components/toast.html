Overview

Toasts confirm what just happened. Errors that need action use an alert or stay until dismissed.

Anatomy

  1. IconTone colour.
  2. Title + textInverse text.
  3. Action (optional)Undo/View/Retry.
  4. Dismiss24px button.

Sizes

Max width 360px.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Responsive behaviour

  • Bottom-right on desktop; full width above the bottom nav on phones.

Theming

Inverse surface; icons in tone colours with ≥3:1 on inverse.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

A persistent role="status" region (polite) receives toasts; errors use role="alert". Timers (5s) pause on hover and focus; errors persist.

Keyboard

KeyAction

EscDismisses the focused toast.

Toasts never steal focus.
