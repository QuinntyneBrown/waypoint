Checkbox

Independent yes/no choices and multi-select lists: consents, filters, remember me.

Overview

Use a checkbox when each option is independent, or for a single opt-in. For one-of-many use a radio group; for a setting that applies immediately use a switch.

Anatomy

  1. Box20px, 4px radius, ink fill when checked (lime in dark).
  2. LabelBody text; the whole row is clickable.
  3. Description (optional)Muted 14px.

Sizes

One size (20px box, 24px+ row target).

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Checkbox

Both themes

Indeterminate is set from script (input.indeterminate = true) for a parent of a partially selected group.

Responsive behaviour

  • Rows stack vertically; inline groups wrap.

Theming

Checked fill --color-accent, tick --color-fg-on-accent. Light: ink box with white tick. Dark: lime box with ink tick.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

Native <input type="checkbox"> visually hidden inside its <label>; groups in <fieldset> with <legend>.
