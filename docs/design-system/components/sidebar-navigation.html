Overview

Primary navigation for signed-in roles at 960px and up. Below that it becomes a drawer opened from the top bar, and youth/guardian roles switch to the bottom navigation.

Anatomy

  1. Group labelOverline, muted.
  2. ItemIcon + label, 8px radius.
  3. Current itemInk fill, white text; aria-current="page".
  4. BadgeLime count.

Responsive behaviour

  • ≥960px: fixed at the left under the top bar.
  • <960px: off-canvas drawer with a scrim; focus moves into it and is trapped until closed.

Theming

Current item uses --color-accent/--color-fg-on-accent: ink in light, lime with ink text in dark.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

<nav aria-label="Main"> with links; current page aria-current="page". Drawer mode follows the dialog pattern.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows a link.
EscCloses the drawer (small screens).

Inset focus ring inside the item.
