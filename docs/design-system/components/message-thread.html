Message thread

Mentor and youth conversations: incoming and outgoing bubbles with day separators.

WCAG 2.2 AALight + dark

Overview

Used only in Messages. Bubbles are short; long content goes in attachments.

Anatomy

  1. Day separatorCaption, centred.
  2. IncomingNeutral, left.
  3. OutgoingAccent, right.
  4. TimeCaption under text.

Variants

Incoming and outgoing are shown in anatomy.

Sizes

Bubbles max 75% width.

States

Bubbles are static text; sending/failed states show as meta text ("Sending…", "Not sent · Retry").

Responsive behaviour

  • Max width 75%, capped at 512px.

Theming

Outgoing uses accent (ink in light, accent in dark).

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

An ordered log: role="log" with aria-live="polite"; each bubble includes sender for screen readers.
