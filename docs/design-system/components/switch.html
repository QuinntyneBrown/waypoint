Switch

Turn a setting on or off immediately: notification channels, feature toggles, publish states.

Overview

Use a switch when the change takes effect at once with no Save button. In a form that is submitted later, use a checkbox.

Anatomy

  1. Track44×24, --color-border-strong off, --color-accent on.
  2. Thumb20px surface-coloured circle.
  3. LabelNames the setting.

Variants

Label right, label left (settings rows), with description.
HTML
<label class="w-switch"><input type="checkbox" role="switch" checked><span class="w-switch__track"></span>Weekly digest</label><label class="w-switch w-switch--start"><input type="checkbox" role="switch"><span class="w-switch__track"></span><span>Push notifications<span class="w-check__desc">On this device only.</span></span></label>

Sizes

One size.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

VariantOffHoverFocusOnDisabled
Switch

Both themes

Responsive behaviour

  • Settings rows put the switch at the right edge on every width.

Theming

Off track --color-border-strong (3:1 vs surface), on track --color-accent, thumb --color-bg-surface.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
