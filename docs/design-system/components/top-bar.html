Overview

Every signed-in screen has one top bar. It carries global tools only; page actions belong in the page header.

Anatomy

  1. Menu buttonBelow 960px; toggles the sidebar drawer.
  2. BrandLime mark + wordmark, links home.
  3. Track switcherMenu button; label hides under 640px.
  4. ActionsNotifications, account.

Sizes

Fixed at --layout-topbar-height (56px); the public nav is 64px.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Responsive behaviour

  • ≥960px: no menu button; sidebar is always visible.
  • <960px: menu button appears; sidebar becomes a drawer.
  • <640px: track switcher shows its icon only (name stays in aria-label).

Theming

Surface --color-bg-surface with a hairline bottom border; in dark the border carries the separation.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

<header> landmark; menu button has aria-expanded and aria-controls pointing at the sidebar.
