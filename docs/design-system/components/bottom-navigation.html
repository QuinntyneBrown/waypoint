Bottom navigation

Overview

Shown below 960px for youth and guardian roles. Holds the top destinations only; everything else lives in the drawer.

Anatomy

  1. Item24px icon above a 12px label.
  2. CurrentLime pill behind the icon, ink label.
  3. BarSurface with a hairline top border; respects the safe-area inset.

Responsive behaviour

  • Hidden at 960px and up.
  • Labels truncate with ellipsis below 340px; never drop labels.

Theming

Current icon pill uses --color-brand in both themes.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
