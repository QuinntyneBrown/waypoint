Overview

A real <input type="file"> is the control; the drop zone is an enhancement around it.

Anatomy

  1. Drop zoneDashed 2px border on sunken fill.
  2. ButtonLabel wrapping the file input.
  3. ConstraintsTypes and size, always visible.

Sizes

One size; the zone fills its column.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Uploading shows a determinate progress bar per file; failed shows the reason and a Retry button.

Responsive behaviour

  • On touch devices the copy changes to "Choose a file"; dragging is not offered.

Theming

Zone uses --color-bg-surface-sunken; dragging switches to --color-accent-subtle with an accent border.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

Native file input inside a label; progress uses role="progressbar"; status messages in a polite live region.
