Empty state

Overview

Every list and table has an empty state with a reason and a next step.

Anatomy

  1. Icon64px greige circle.
  2. Title20px heading.
  3. TextOne sentence.
  4. ActionOne primary; optional link.

Variants

No matches

Try a different name or clear filters.

You do not have access

Ask a program admin to add you to this cohort.

Could not load lessons

Check your connection and try again.

No results, permission, error.
