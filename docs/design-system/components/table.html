Overview

Use a table to compare records across the same fields. Under 768px, tables with .ph-table--cards turn each row into a labelled card.

Anatomy

  1. WrapperHairline border, 8px radius, scrolls horizontally.
  2. HeaderOverline on neutral grey.
  3. Main cellAvatar + name, semibold.
  4. Row actionSmall icon button, labelled per row.

Loading shows skeleton rows inside the same table; empty and error show an empty state in place of the body, keeping the header so filters stay visible.

Responsive behaviour

  • ≥768px: table; wrapper scrolls horizontally if needed.
  • <768px with .ph-table--cards: each row is a card, cells show their header via data-label.
  • Progress matrix keeps a sticky first column and scrolls horizontally.

Theming

Header --color-bg-surface-sunken; selected row --color-accent-subtle.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

Native <table> with <caption> and scope. Sortable headers contain a button and set aria-sort. Selection uses checkboxes, each labelled with the row's name.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceSort / select / open row action.

Focus

Every interactive element in the row is reachable; rows themselves are not focusable.

Labelling

Row actions include the row's name: "Actions for Maya Ortiz".
