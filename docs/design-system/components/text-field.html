Text field

Single-line inputs for names, emails, passwords, numbers and search.

Overview

Use a text field for short free-form answers. Every field sits in a form field wrapper with a visible label. For several lines use a textarea; for a fixed list use a select.

Anatomy

  1. LabelInter 600 14px above the input.
  2. Input44px, 1.5px --color-border-strong, --radius-md.
  3. Help text14px muted, linked with aria-describedby.

Variants

At least 12 characters.

Sizes

Medium (44px) is the default. Small (32px) only in table filters; large (52px) on auth screens.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

VariantDefaultHoverFocusInvalidDisabledRead-only
Input

Both themes

Errors show only after the person leaves the field or submits, then re-validate as they type. Read-only uses a dashed border and sunken fill so it does not look disabled.

Responsive behaviour

  • Inputs are always full width of their column; forms use one column below 768px.
  • Font size stays 16px on phones so iOS does not zoom on focus.

Theming

Reads --field-border (defaults to --color-border-strong, becomes --color-danger-solid on error). Focus switches to a solid 2px ring in --color-focus-ring.

Component tokens (declared in components.css, override per variant or theme): --field-border.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

Native <input> with a <label for>. Help and error text are joined with aria-describedby; invalid fields set aria-invalid="true". Use the right type, autocomplete and inputmode.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
TypeEdits the value.
Esc (search)Clears the search field.

Focus

Solid 2px focus ring replaces the mocks' 3px lime halo, which measured 1.2:1 and failed 2.4.11.

Labelling

Visible label always; placeholder is an example, never the label. Required fields show a red asterisk and set required.

Touch

Content

  • Labels are nouns: "Email", "Date of birth".
  • Help text says why or what format: "We send your invite here."
  • Errors say what to do: "Enter an email like name@example.com".
