Textarea

Multi-line text: application answers, mentor feedback, announcements.

Overview

Use a textarea when the answer may run past one line. Show a counter when there is a limit.

Anatomy

  1. LabelAbove.
  2. Text area104px minimum, resizes vertically.
  3. CounterCaption, right-aligned, announced politely near the limit.

Variants

Two or three sentences is plenty.

Plain and with counter.
HTML
<div class="ph-field"><label class="ph-label" for="tv1">Why do you want to join?</label><textarea class="ph-textarea" id="tv1" rows="3"></textarea><p class="ph-help" id="tv1-h">Two or three sentences is plenty.</p></div>

Sizes

One size; height comes from rows (minimum 3) and grows vertically.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

VariantDefaultHoverFocusInvalidDisabledRead-only
Textarea

Both themes

Responsive behaviour

  • Full width; resize handle vertical only so layouts do not break.

Theming

Same tokens as the text field.

Component tokens (declared in components.css, override per variant or theme): --field-border.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
