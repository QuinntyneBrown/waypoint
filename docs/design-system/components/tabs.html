Tabs

Switch between related panels of content on one page.

Overview

Use tabs for peer views of one object (Overview, Lessons, Badges). Use a segmented control to filter the same content, and separate pages when views are unrelated.

Anatomy

  1. Tab listHairline bottom border, scrolls horizontally.
  2. TabSpace Grotesk 14px, 44px tall.
  3. Indicator2px --color-accent under the selected tab.
  4. Count (optional)Neutral badge.

Variants

Underline (default) and pill.
HTML
<div class="w-tabs w-tabs--pill" role="tablist" aria-label="Status"><button class="w-tab" role="tab" type="button" aria-selected="true">Pending</button><button class="w-tab" role="tab" type="button" aria-selected="false" tabindex="-1">Sent</button><button class="w-tab" role="tab" type="button" aria-selected="false" tabindex="-1">Expired</button></div>

Sizes

Medium (44px) default; small (32px) inside cards.
HTML
<div class="w-tabs w-tabs--sm" role="tablist" aria-label="Small"><button class="w-tab" role="tab" type="button" aria-selected="true">Week</button><button class="w-tab" role="tab" type="button" aria-selected="false" tabindex="-1">Month</button></div>

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Responsive behaviour

  • Tab list scrolls horizontally on phones; the selected tab scrolls into view.
  • Do not wrap tabs to two rows.

Theming

Indicator and selected pill use --color-accent.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

WAI-ARIA APG Tabs with automatic activation: role="tablist/tab/tabpanel", aria-selected, aria-controls, roving tabindex.
