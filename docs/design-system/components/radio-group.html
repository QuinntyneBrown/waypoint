Overview

Use radios for 2–6 mutually exclusive options that people should compare. More options: select.

Anatomy

  2. Radio20px circle, 10px ink dot when checked.
  3. LabelThe answer.

Sizes

One size.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Radio

Both themes

Responsive behaviour

  • Horizontal groups wrap; card-style stacks to one column under 640px.

Theming

Checked ring and dot --color-accent.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
