Link

Links take people somewhere: another page, a section, a file or an external site.

Overview

Use a link for navigation. If activating it changes data, use a button. In Waypoint, links are ink (lime in dark) and always underlined inside text, because colour alone does not separate them from ink body copy.

Anatomy

  1. LabelDescribes the destination.
  2. Underline1px at rest, 2px on hover, 3px offset.

Sizes

Links inherit the size of the text around them.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Visited links keep the same colour: Waypoint lists are task lists, and a colour change would read as 'done'.

Responsive behaviour

  • Standalone links in cards keep a 24px minimum target height.
  • Long URLs wrap with overflow-wrap: anywhere; never show raw URLs as link text.

Theming

--color-fg-link and --color-fg-link-hover. Light: ink to black. Dark: lime-300 to lime-100.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

Native <a href>. External links open in the same tab unless the person would lose work; if a new tab is used, say so in the name.

Keyboard

KeyAction
TabMoves to the link.
EnterFollows the link.

Focus

Focus ring with 2px offset hugging the text.

Labelling

Link text must make sense out of context ("Read the consent policy", not "here").

Content

  • Never "click here" or "read more" alone.
