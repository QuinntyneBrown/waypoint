Menu

A dropdown list of actions or choices opened from a button: track switcher, notifications preview, row actions.

Overview

Use a menu for three or more related actions behind one trigger, or for the track switcher in the top bar. For choosing a value in a form, use a select.

Anatomy

  1. PanelRaised surface, --radius-lg, --shadow-3, 4px padding.
  2. ItemIcon, label, optional shortcut; 32px minimum height.
  3. Separator1px --color-border-default.
  4. Danger item--color-danger-fg.

Sizes

Menus have one size; width grows with content from 200px.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Item

Both themes

Responsive behaviour

  • Menus open below the trigger and flip above when there is no room.
  • On phones, long menus become a bottom sheet (see drawer).

Theming

Panel --color-bg-surface-raised; in dark this is lighter than the surface beneath, so elevation reads without relying on the shadow.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

WAI-ARIA APG Menu Button: trigger has aria-haspopup="menu" and aria-expanded; menu has role="menu"; items are menuitem / menuitemradio.

Keyboard

KeyAction
Enter, Space, ↓On the trigger: opens the menu and focuses the first item.
↑ / ↓Moves between items, wrapping.
Home / EndFirst / last item.
A–ZType-ahead to the next item starting with that letter.
EscCloses and returns focus to the trigger.
TabCloses the menu and moves on.

Focus

Roving focus: the focused item gets a subtle fill plus an inset 2px ring.

Labelling

The menu is labelled by its trigger (aria-labelledby). Disabled items stay in the list with aria-disabled so people learn they exist.

Motion

Opens with a 200ms fade; none under reduced motion.

Touch

Items are 32px minimum, 40px on touch devices via padding.

Content

  • Items are verbs ("Duplicate") or destinations ("View all notifications").
  • Put destructive items last, after a separator.
