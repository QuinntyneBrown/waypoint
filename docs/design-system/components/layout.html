Responsive behaviour

  • .ph-grid--2/3/4: 1 column below 640px, 2 columns to 960px, then 3 or 4.
  • Container padding follows --layout-margin: 20px / 32px.

Theming

Theme-agnostic.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
