Pagination

Moves through long tables: applications, audit log, users.

Overview

Use for admin tables over 25 rows. Show the range ("1–25 of 132").

Anatomy

  1. RangeMuted text.
  2. Pages32px pill links.
  3. CurrentInk fill, aria-current.
  4. Prev/nextIcon links, labelled.

Variants

PreviousNext
Simple prev/next.
HTML
<nav class="ph-pagination" aria-label="Pagination simple"><a class="ph-btn ph-btn--ghost ph-btn--sm" href="#variants">Previous</a><a class="ph-btn ph-btn--ghost ph-btn--sm" href="#variants">Next</a></nav>

Sizes

One size.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Responsive behaviour

  • On phones only prev/next and "Page 2 of 6" show.

Theming

Current uses accent.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
