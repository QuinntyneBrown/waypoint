Progress

Overview

Bars for linear progress in lists and tables; rings for headline completion on dashboards.

Anatomy

  1. Track8px pill, neutral grey with hairline edge.
  2. FillAccent; accent variant for youth celebrations.
  3. Valuethe rounded display face tabular.

Responsive behaviour

  • Bars fill their container; rings keep their size.

Theming

Fill --color-accent (ink/accent); accent brand fill gets a strong inset edge so it reads on neutral grey.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

role="progressbar" with aria-valuenow/min/max and a label; indeterminate omits valuenow. Rings are role="img" with the value in aria-label.
