Overview

Use for navigation on small screens and for detail that keeps the list visible behind it. It is modal: same rules as the dialog.

Anatomy

  1. ScrimBackdrop.
  2. PanelUp to 416px, full height.
  3. HeaderTitle + close.

Variants

Left: .w-drawer--left.

Right (detail) and left (navigation).
HTML
<p>Left: <code>.w-drawer--left</code>.</p>

Sizes

Width min(26rem, 100%).

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.
