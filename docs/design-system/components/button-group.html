Button group

A segmented control: two to five mutually exclusive options in one pill, used for view switches and filters.

WCAG 2.2 AALight + dark

Overview

Use a segmented control to switch the view of the same content (Week / Month, Cards / Table, All / Pending / Approved). Use tabs when each option shows different content, and a select when there are more than five options.

Anatomy

  1. Track--color-bg-subtle-hover pill with 2px padding.
  2. Selected segmentSurface fill with --shadow-1, aria-pressed="true".
  3. Unselected segmentMuted label, no fill.

Variants

Segmented (single select) and a toolbar of independent toggles.
HTML
<div class="ph-segment" role="group" aria-label="Applications filter"><button class="ph-segment__item" type="button" aria-pressed="true">All</button><button class="ph-segment__item" type="button" aria-pressed="false">Pending</button><button class="ph-segment__item" type="button" aria-pressed="false">Approved</button></div><div class="ph-cluster" role="group" aria-label="Text formatting"><button class="ph-btn ph-btn--ghost ph-btn--sm ph-btn--icon" type="button" aria-pressed="true" aria-label="Bold"><b>B</b></button><button class="ph-btn ph-btn--ghost ph-btn--sm ph-btn--icon" type="button" aria-pressed="false" aria-label="Italic"><i>I</i></button></div>

Sizes

Small (32px segments) is the default; medium (44px) for touch-first youth screens.
HTML
<div class="ph-segment" role="group" aria-label="Size sm"><button class="ph-segment__item" type="button" aria-pressed="true">Cards</button><button class="ph-segment__item" type="button" aria-pressed="false">Table</button></div><div class="ph-segment ph-segment--md" role="group" aria-label="Size md"><button class="ph-segment__item" type="button" aria-pressed="true">Cards</button><button class="ph-segment__item" type="button" aria-pressed="false">Table</button></div>

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

VariantDefaultHoverFocusPressedDisabled
Segment

Both themes

Responsive behaviour

  • The group never wraps; on phones it can stretch full width with equal segments.
  • With more than three long labels on a phone, switch to a select.

Theming

Track uses --color-bg-subtle-hover, selected segment --color-bg-surface. In dark the selected segment is the near-black surface on a lighter track, so it reads as raised.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

A role="group" with aria-label holding buttons with aria-pressed. Changing the selection updates the view in place without moving focus.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceSelects the focused segment.

Focus

Each segment takes the focus ring, inset by 2px so it stays inside the track.

Labelling

Group label names what is being switched ("Calendar view"); segment labels are short nouns.

Motion

Fill fades over --duration-fast.

Touch

Small segments are 32px tall; use medium on touch-first screens.

Content

  • One or two words per segment, nouns, sentence case.
  • Counts go after the label: "Pending 4".
