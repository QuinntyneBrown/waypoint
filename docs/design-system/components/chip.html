Chip

Pill-shaped filters and removable tags.

Overview

Filter chips toggle a filter (aria-pressed). Input chips show chosen values with a remove button. Static chips are just labels (prefer badges).

Anatomy

  1. Pill32px, 1.5px strong border.
  2. LabelInter 500 14px.
  3. Remove (input chips)24px labelled button.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Theming

Selected uses accent.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
