Overview

Use on admin pages three or more levels deep (Tracks / Bible & Leadership / Module 2 / Lesson editor). The mocks use a back link instead on shallow pages; keep that.

Anatomy

  1. AncestorsUnderlined muted links.
  2. SeparatorSlash, decorative.
  3. Current pagePlain text, aria-current="page".

Variants

  1. Tracks
  3. Lesson 4
Collapsed with ellipsis on phones.
HTML
<nav class="w-breadcrumb" aria-label="Breadcrumb collapsed"><ol><li><a href="#variants">Tracks</a></li><li><button class="w-btn w-btn--link" type="button" aria-label="Show 2 more levels">…</button></li><li><span aria-current="page">Lesson 4</span></li></ol></nav>

Sizes

One size (14px).

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Responsive behaviour

  • Below 640px middle levels collapse into an ellipsis button.

Theming

Muted links, default current text.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
