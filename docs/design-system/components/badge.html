Overview

Badges label; they are not buttons. For filters use a chip.

Anatomy

  2. Labelthe rounded display face 600 12px.

Responsive behaviour

  • Never wrap; truncate the surrounding text first.

Theming

Each tone reads its status -bg/-fg pair through --badge-bg/--badge-fg.

Component tokens (declared in components.css, override per variant or theme): --badge-bg, --badge-fg.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
