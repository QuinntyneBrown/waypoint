Select

Choose one value from a known list: track, cohort, role, country.

Overview

Use the native select for 4–20 options. Fewer options: radio group. Many or searchable: a combobox (not yet in the mocks).

Anatomy

  1. LabelAbove.
  2. ControlNative select, 44px, custom chevron drawn with gradients in currentColor.
  3. ChevronInherits text colour, so it themes automatically.

Variants

Native and with a placeholder option.
HTML
<div class="ph-field"><label class="ph-label" for="sv1">Cohort</label><select class="ph-select" id="sv1"><option value="">Choose a cohort</option><option>Spring 2026</option><option>Fall 2026</option></select></div>

Sizes

Small for table filters, medium default, large on auth.
HTML
<select class="ph-select ph-select--sm" aria-label="Small"><option>Small</option></select><select class="ph-select" aria-label="Medium"><option>Medium</option></select><select class="ph-select ph-select--lg" aria-label="Large"><option>Large</option></select>

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

VariantDefaultHoverFocusInvalidDisabled
Select

Both themes

Responsive behaviour

  • Full width of its column. Native picker on phones.

Theming

Same tokens as the text field; chevron uses currentColor.

Component tokens (declared in components.css, override per variant or theme): --field-border.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

Native <select>. A custom listbox only when native cannot do the job, then APG Listbox.
