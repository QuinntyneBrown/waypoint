Card

The basic surface: groups related content with a hairline border and 8px corners.

Overview

Cards hold one topic each: a stat, a lesson, a person. Brand variants (ink, accent, neutral grey) give hierarchy on dashboards; use at most one accent card per view.

Anatomy

  1. HeaderTitle + optional badge/action, 20px padding.
  2. Body20px padding.
  3. FooterHairline top border, actions.

Sizes

Cards fill their grid cell.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; real pages get them from :hover, :focus-visible, :active and ARIA attributes.

Selected cards use aria-selected inside a listbox/grid, or aria-current for the current item.

Responsive behaviour

  • Cards stack to one column under 640px (see layout).
  • Padding stays 20px at all sizes.

Theming

Default --color-bg-surface; neutral grey --color-bg-surface-sunken; ink --color-bg-inverse; accent --color-brand. In dark, ink cards invert to light, which keeps them the highest-contrast card.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.
