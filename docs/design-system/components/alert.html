Responsive behaviour

  • Actions wrap under the text on phones.

Theming

Tone pairs from status tokens through --alert-* component tokens.

Component tokens (declared in components.css, override per variant or theme): --alert-bg, --alert-fg, --alert-icon, --alert-border.

Dark theme applies with [data-theme="dark"] or the OS preference; the component itself has no theme-specific CSS.

Accessibility

Role and pattern

role="alert" only for new urgent content; role="status" for banners; plain otherwise.
