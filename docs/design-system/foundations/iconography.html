Iconography

93 outline icons on a 24-unit grid with 2px round strokes, drawn in currentColor.

WCAG 2.2 AALight + dark
  • Overview
  • Icon set
  • Sizes
  • Usage

Overview

The icon set lives in docs/mocks/assets/js/waypoint.js (Feather-style paths). Use <svg class="w-icon" aria-hidden="true" viewBox="0 0 24 24">.

Icon set

Sizes

  • 16px inline with captions and badges (rendered at 14px inside badges).
  • 18px in buttons.
  • 20px default (nav, alerts, toasts).
  • 24px bottom nav; 30px empty states; 34px medals.

Usage

  • Icons inherit colour; never set a fill colour inline.
  • Decorative icons get aria-hidden="true"; meaning lives in adjacent text or the control's aria-label.
  • Status icons pair with text: check-circle (success), alert-triangle (warning), alert-circle (danger), info (info).
