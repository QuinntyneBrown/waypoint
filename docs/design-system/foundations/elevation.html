Elevation

Four shadow levels and explicit layers distinguish surfaces without competing with content.

Extracted 25 October 2026Light + dark contrast verified

Principles

Cards use shadow 1; dropdowns use 2; menus and popovers use 3; dialogs use 4. In dark mode the canvas is darker than the surface, which is darker than the raised surface. Layers progress from base to sticky, dropdown, overlay, modal, popover, toast and tooltip. Never introduce local z-index numbers.
