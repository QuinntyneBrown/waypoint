Typography

Space Grotesk for headings and UI labels, Inter for reading, Fraunces for scripture, JetBrains Mono for code.

WCAG 2.2 AALight + dark

Overview

Four families, all bundled in assets/fonts.css (copied from the mocks; no external requests). Headings are Space Grotesk 500 with tight tracking; body is Inter 400 at 16px / 1.5 with −0.01em tracking, as in the mocks.

Usage

  • Body text never drops below 16px; nothing is smaller than 12px.
  • Headings: h1 44px (clamps to 32px on phones), h2 32px, h3 22px, h4 18px.
  • Uppercase overlines (eyebrows, table headers) use --text-overline with --letter-spacing-wide.
  • Measure: prose is capped at --layout-measure (65ch).
  • Numbers in tables and stats use font-variant-numeric: tabular-nums.

Accessibility

  • Text resizes to 200% without loss: sizes are in rem.
  • Line height ≥ 1.5 for body; paragraph spacing 1em (WCAG 1.4.12).
  • Scripture uses 1.6 line height for long reading.
