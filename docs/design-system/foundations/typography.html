Typography

Rounded system type keeps names, instructions and high-priority information legible.

Extracted 25 October 2026Light + dark contrast verified

Principles

Body copy is 16px with 1.5 line height. Captions never fall below 12px. Use 30px section titles and 36px page titles sparingly on phones. Quick Cards use 18px emergency information. Preserve names and accents; tabular numbers align attendance counts. Prose caps at 65ch.
