Foundation

Color

A warm ink-and-greige neutral ramp, one lime brand hue and four status hues. Lime marks the one primary action; ink marks selection and focus.

WCAG 2.2 AALight + dark

Overview

Waypoint's palette comes from the FaithTech brand used across the mocks: lime #c6fb50, ink #16160c and warm greige neutrals. Status hues (green, amber, tomato, teal) are deepened from the mock values until every text pair passes 4.5:1.

  • Brand (--color-brand, lime) fills the primary button, brand mark, current bottom-nav icon and celebration moments. Lime never carries text colour on white; it is a fill with ink text.
  • Accent (--color-accent) marks selection: current nav item, checked boxes, selected tab, focus ring. Ink in light, lime in dark.
  • Neutrals are warm, never blue-grey.

Usage

  • One lime primary per view; never lime text on light surfaces.
  • Status colour always comes with an icon or a word.
  • Use --color-fg-muted for secondary text, never opacity or alpha ink (the mocks' --w-ink-60/-45 varied with the background).
  • Adding a brand theme: override semantic tokens in a new [data-theme="<name>"] block and add its pairs to contrast-pairs.json; see theming.

Contrast pairs

Every pairing in tokens/contrast-pairs.json, measured live. Normal text needs 4.5:1; UI edges, icons and focus rings need 3:1. check_contrast.py verifies the same list in CI.
