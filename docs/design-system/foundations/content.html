Content

Warm, plain, encouraging. Written for 10–18 year olds and the adults around them.

Overview

Waypoint speaks like a good mentor: clear, kind, specific. Faith language is welcome where it belongs (lessons, scripture), never in system messages.

Voice and tone

  • Youth screens: encouraging and brief ("Nice work — 3 lessons this week").
  • Guardian screens: reassuring and factual.
  • Admin screens: neutral and precise.

Mechanics

  • Sentence case everywhere, including buttons and headings.
  • Buttons are verbs: "Send invite", "Start lesson".
  • Dates: 12 Mar 2026; times: 6:30 pm; relative only under a week, with the absolute date on hover/title.
  • Numbers: numerals; ranges with an en dash (1–25).
  • Names: first name for youth, full name in admin tables.

Error formula

What happened + how to fix it. "We couldn't send the invite. Check the email address and try again." No blame, no codes in the main text.

Empty-state formula

What is empty + why + next step. "No applications yet. When young people apply, they appear here." + one action.
