Foundation

Motion

Short, functional transitions. Nothing moves that does not explain a change.

WCAG 2.2 AALight + dark
  • Overview
  • Durations
  • Usage
  • Reduced motion

Overview

The mocks used nine durations (.12s–.4s) and the CSS ease keyword; these became four steps and a standard curve equal to ease.

Durations

Usage

  • Hover and colour: fast (150ms).
  • Fades, dialog pop, tab panel: base (200ms).
  • Sidebar drawer, toast slide-in: slow (250ms).
  • Progress fill: deliberate (400ms).
  • Enter with --ease-enter, leave with --ease-exit, faster than entering.

Reduced motion

Under prefers-reduced-motion: reduce the duration tokens drop to 0.01ms, and components.css removes shimmer and slide keyframes. Spinners keep turning because they communicate status.
