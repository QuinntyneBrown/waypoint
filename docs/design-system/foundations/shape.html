Foundation

Shape

Pills for controls, soft 8px cards, 14px dialogs and a 1.5px hairline stroke.

WCAG 2.2 AALight + dark
  • Overview
  • Radii
  • Usage
  • Tokens

Overview

Buttons, badges, chips and avatars are full pills (the most recognisable trait of the brand). Inputs use 6px, cards 8px, dialogs 14px. The mocks' 1.5px border width is kept as the default stroke.

Radii

--radius-xs
--radius-sm
--radius-md
--radius-lg
--radius-xl
--radius-full

Usage

  • Radius grows with element size: input md, card lg, dialog xl.
  • Never mix pill and square buttons on one view.
  • Twenty distinct radii in the mocks (5px, 7px, 10px…) collapsed to five.
