Spacing

A 4px base scale sets consistent inside and between spacing.

Extracted 25 October 2026Light + dark contrast verified

Principles

Use 4–8px between icon and text, 12–16px inside compact groups and 24px inside large cards. Page sections use the current layout gutter: 16px on phones, 24px on tablets and 32px on laptops. The 2px half-step remains only for hairline relationships. The extracted 6px overlay offset was corrected to 8px.
