Spacing

A 4px scale from 0 to 96px. Components use up to 24px inside; layouts use 24px and up between.

Usage

  • Inside components: 4–24px (--space-1…--space-6).
  • Card padding: --space-5 (20px). Dialog padding: --space-6.
  • Between fields: --space-5; between page sections: --space-8.
  • Cluster gaps: --space-3; stack gaps: --space-5.
