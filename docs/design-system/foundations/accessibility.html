Overview

The commitments below are what every component page's Accessibility section proves.

Commitments

  • 1.4.3 / 1.4.11: text 4.5:1, UI edges and icons 3:1, in both themes (checked by check_contrast.py).
  • 1.4.1: colour is never the only signal; status has text or icons.
  • 2.4.7 / 2.4.11: visible focus ring, 2px, 3:1 against adjacent colours, never hidden by sticky bars.
  • 2.5.8: targets ≥ 24px; comfortable 44px.
  • 1.4.10 / 1.4.4: reflow at 320px, resize to 200%.
  • 1.4.12: text spacing overrides do not break layouts.
  • 2.1.1: everything works by keyboard; no keyboard traps except modal focus containment.
  • 4.1.2: native elements first; ARIA only per APG patterns.
  • 2.3.3: reduced motion respected.
  • 3.3.1 / 3.3.3: errors identified in text with a suggestion.

Component contract

  • Name, role and state exposed (labels; aria-pressed, aria-selected, aria-current, aria-expanded, aria-invalid, aria-busy).
  • Keyboard map documented.
  • Contrast pairs listed in contrast-pairs.json.
  • Works in forced-colors mode.

Testing procedure

  • Keyboard-only pass on every flow.
  • Screen reader smoke test (NVDA + Firefox, VoiceOver + Safari).
  • axe in CI for every mock.
  • Zoom to 200% and 400%.
