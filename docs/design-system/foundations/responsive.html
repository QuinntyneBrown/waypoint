Responsive

Mobile first, with one decisive breakpoint at 960px for the app shell.

WCAG 2.2 AALight + dark

Overview

Most Waypoint youth use phones; admins use laptops. Every screen is designed at 360px first.

Component behaviours

Component< 640px640–959px≥ 960px
ShellTop bar + bottom nav (youth, guardian) or drawerTop bar + drawerTop bar + sidebar

Touch

  • Comfortable target 44px (--target-comfortable); minimum 24px with spacing.
  • No hover-only affordances.
  • Inputs stay 16px to avoid iOS zoom.

Testing matrix

  • 360, 768, 1280px.
  • Both themes.
  • 200% zoom and 320px reflow.
