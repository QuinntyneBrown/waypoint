Layout

Overview

Mobile first. The key breakpoint is 960px, where the app shell switches from top bar + bottom nav (or drawer) to top bar + fixed sidebar.

Breakpoints and grid

RangeColumnsGutterMarginShell
< 768px416px20pxTop bar + bottom nav / drawer
768–959px820px32pxTop bar + drawer
≥ 960px1224px32pxTop bar + sidebar

Live grid

Page templates

  • App shell (desktop, mobile): top bar, sidebar/bottom nav, .w-container .w-page.
  • Auth (template): centred 420px card on greige, or split with ink aside at 900px+.
  • Public (template): marketing nav, hero, ink footer.
  • State (template): loading, empty, error variants of a page.

Usage

  • Use .w-container (1200px), --wide (1440px) for tables and calendar, --narrow (760px) for forms.
  • Grids: .w-grid--2/3/4, never fixed column counts.
  • Page header: title + sub on the left, actions on the right; wraps on phones.
