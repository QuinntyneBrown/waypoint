Design system

Waypoint design system

The visual and interaction language of Waypoint, FaithTech's youth discipleship and coding programme, built on the PromiseHub design system: tokens, foundations, components and patterns in light and dark, with the ph prefix.

How to use

<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="assets/components.css">

<button class="ph-btn ph-btn--primary" type="button">Start lesson</button>
  • Copy class names from each component's Code section.
  • Read tokens from tokens/tokens.json (DTCG) to generate platform constants.
  • Set data-theme="dark" on any element to force dark; otherwise the OS preference applies.
  • Press t on any page to toggle the documentation theme.
