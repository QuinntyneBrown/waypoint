Pattern

Forms

How Waypoint asks for information: applications, invites, settings.

WCAG 2.2 AALight + dark
  • Overview
  • When to use
  • Structure
  • States
  • Responsive
  • Accessibility
  • Content
  • Do and don't
  • Sources

Overview

One column, labels above, validate on blur, summarise on submit, one primary action.

When to use

  • Short task (≤ 6 fields): single card form.
  • Long task (application): multi-step with a stepper and save-as-you-go.
  • Instant settings: switches, no Save button.

Structure

We ask them for consent.

Track
A short invite form.
HTML
<form class="w-card" novalidate style="width:100%;max-width:30rem"><div class="w-card__body"><div class="w-field"><label class="w-label" for="pf-n">Youth name</label><input class="w-input" id="pf-n" autocomplete="name"></div><div class="w-field"><label class="w-label" for="pf-e">Guardian email</label><input class="w-input" id="pf-e" type="email" aria-describedby="pf-eh"><p class="w-help" id="pf-eh">We ask them for consent.</p></div><fieldset class="w-fieldset"><legend>Track</legend><label class="w-radio"><input type="radio" name="pf-t" checked><span class="w-radio__box"></span>Bible &amp; Leadership</label><label class="w-radio"><input type="radio" name="pf-t"><span class="w-radio__box"></span>Coding for Kingdom</label></fieldset></div><div class="w-card__footer" style="justify-content:flex-end"><button class="w-btn w-btn--ghost" type="button">Cancel</button><button class="w-btn w-btn--primary" type="submit">Send invite</button></div></form>

States

  • Pristine → typing (no errors) → blurred invalid (error shown) → re-validated on input.
  • Submitting: primary busy; Failed: error summary focused; Success: toast + navigate.

Responsive

  • Pairs collapse to one column below 640px.
  • Actions full width and stacked on phones.

Accessibility

  • Labels via for; help and errors via aria-describedby.
  • Error summary role="alert" receives focus.
  • Never disable submit to signal errors.

Content

  • Labels are nouns; help says why.
  • Error: what + fix.
