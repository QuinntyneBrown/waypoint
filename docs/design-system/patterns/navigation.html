Navigation and page structure

The shell, the page header and how people move between areas.

Overview

Top bar for global tools, sidebar/bottom nav for areas, page header for the current page's title and actions.

When to use

  • Tabs: peer views of one object.
  • Sub-pages: different objects or tasks.
  • Breadcrumb: three or more levels deep.
  • Back link: one level deep.

States

  • Current page always marked with aria-current.

Responsive

  • Shell switches at 960px.
  • Page actions stack under the title on phones.

Accessibility

  • Landmarks: header, nav (labelled), main, footer.
  • Skip link first.
  • One h1 per page: the page title.

Content

  • Nav labels match page titles.
