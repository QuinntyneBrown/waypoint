Empty and error states

Every list has a first-run, no-results and error state.

Overview

See empty state and error page.

When to use

  • First run: encourage and offer the first action.
  • No results: point at filters.
  • No access: say who can grant it.
  • Error: say what failed and offer retry.

Structure

No youth match “Jo”

Check the spelling or clear the cohort filter.

No-results inside a card.
