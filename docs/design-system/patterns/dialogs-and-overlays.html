Dialogs and overlays

Choosing between dialog, drawer, menu, tooltip and a new page.

Overview

Overlays interrupt; use the lightest one that does the job.

When to use

NeedUse
Confirm a destructive actionSmall dialog (alertdialog)
Short form (≤ 4 fields)Dialog
Review a record beside a listDrawer
Several actions on one itemMenu
Name an iconTooltip
Long or multi-step editPage

States

  • Never stack dialogs; replace content or use a page.
  • Busy and failed states stay inside the dialog.

Responsive

  • Dialogs become bottom sheets under 640px; drawers go full width.

Accessibility

  • Focus in, trapped, returned; Esc closes; background inert.

Content

  • Title is a question for confirmations; buttons repeat the verb.
