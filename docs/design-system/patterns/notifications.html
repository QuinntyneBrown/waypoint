Notifications

Toasts, banners and the notification centre.

WCAG 2.2 AALight + dark

  • Structure
  • States
  • Responsive
  • Accessibility
  • Content

Overview

Three channels by urgency and persistence.

When to use

  • Toast: result of the person's own action.
  • Banner: system condition (offline, maintenance).
  • Notification centre (bell menu + page): things that happened while away (badge earned, quiz graded).

States

  • Unread / read; grouped by day.
  • Toasts auto-dismiss after 5s except errors.

Responsive

  • Bell menu on desktop; full page on phones.

Accessibility

  • Bell label includes the unread count.
  • Toast region polite; never moves focus.

Content

  • Lead with the event: "Quiz graded", then detail.
