Waypoint in Pictures

What this code does, told with big pictures and small words.

It's a clubhouse for a youth program.

Waypoint is a program where young people study the Bible, learn to lead, and learn to code, with a mentor beside them.

This repo is the software that runs it. One place instead of a pile of spreadsheets and group chats.

Six kinds of people, six doors.

Youth, mentors, guardians, volunteers, program staff, and visitors from the street.

Everyone gets their own door and only sees their own rooms. Visitors see the front pages without a key.

Inside: lessons, check-ins, badges.

A young person walks a path of Bible, leadership, and coding lessons. Quizzes and reflections along the way. Finish a track, earn a badge.

A mentor checks in and takes attendance. Staff set up the groups and the schedule.

A gate a parent must open first.

Before a young person can take part, a guardian has to say yes. That consent sits in front of everything.

Safety rules decide who may see whom, and every sensitive action is written down so it can be checked later.

Three pieces make the software.

The screens people see: a public site for anyone, and a portal you sign in to. The brain that decides what is allowed. The memory that keeps it all.

There is also way, a little command-line remote for staff. Changes are pushed to the portal live.

Built test first, every time.

Each thing the app must do is written down as a rule. For each rule, a test is written that fails. Then just enough code is added until the test passes.

A checker refuses new code if any rule is missing its test.

What's in the box.

Five folders. Brain, screens, plan, how-tos, checkers.

Finished, but not open for real kids yet.

The code does everything it was asked to do, and the checkers agree.

It has not had outside safety, privacy, and accessibility reviews. Until then it runs on pretend data only.
