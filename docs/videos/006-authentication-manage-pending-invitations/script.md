# 006 · Managing pending invitations

## Welcome

Not every invitation gets accepted straight away. People lose emails, or the wrong address gets typed. This video shows how staff keep track of pending invitations, send a fresh link, or cancel an invitation so its link stops working.

[pause 2s]

## Tracking an invitation

Pat Morgan, a program administrator, invited David Osei earlier this week. Pat opens the invitations page and finds the invitation on the right, using the search box. The row shows who it is for, the role, who sent it, and the status. David has not accepted yet, so the status says pending. The row also shows the date the link expires.

Pending rows have two buttons, resend and revoke. Links that have expired show the same two buttons, so staff can recover those too.

[pause 2s]

## Sending a fresh link

David says he cannot find the email. Pat presses resend. A message appears that says, a fresh invitation was sent to David's address. David now has a new link with a new expiry.

[pause 2s]

## Cancelling an invitation

Now suppose the invitation should never have gone out. Pat presses revoke. Waypoint does not act at once. It asks, revoke now, with a confirm button and a cancel button, so a stray click cannot cancel anything by mistake.

When Pat confirms, a message says the invitation was revoked. The status changes to revoked, and the row now says no actions. The link stops working immediately.

If anyone opens that link afterwards, they see a page that says, this invite is no longer active. It offers a button, request a new invite, so the person is not left at a dead end.

[pause 2s]

## Things to remember

Staff can search the invitations and see the status of each one. Resend gives a fresh link and a fresh expiry. Revoke asks you to confirm, and then the link stops working right away. A person who opens a dead link is offered a way to ask for a new invite.
