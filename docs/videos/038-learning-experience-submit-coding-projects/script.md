# 038 · Submitting a coding project

## Welcome

Some lessons in Waypoint are not about reading. They are about building. This short video shows how a young person works through a coding lesson, and how the finished project reaches a mentor for review.

[pause 2s]

## The coding lesson

Meet Amara. She opens a coding lesson called, build a welcome card. At the top, a progress bar says zero percent, and a line says, zero of two checks toward the Code Starter badge.

Below that, the lesson is split into steps. Step one is, add a welcome heading. Each step explains the task and shows a code sample. On the right there is a code editor, and under it a live preview, so Amara can see her page change as she types.

[pause 2s]

## Finishing the lesson

Amara changes the heading, and Waypoint saves her workspace as she goes. If she closes the page and comes back, her code is still there. When a step looks right, she ticks its box. When she has ticked both, the bar reaches one hundred percent, and the page says, badge earned. Finishing the lesson counts toward the badge, so her progress is recorded.

[pause 2s]

## Sending it for review

Further down, a section says, send your project for mentor review. It explains that her current code will become a read-only submitted copy. She can leave an optional note to her mentor. Amara writes, please check whether my introduction is clear.

Before she can send it, she must tick a box that says, this is my own work. Then she presses, submit coding project, and confirms.

[pause 2s]

## What happens next

Waypoint takes her to the submission status page. It shows the status, submitted, a copy of her code, and her note to the mentor. Below that is a timeline that goes from submitted to under review. A coding project follows the same review path as any other assignment, so Grace, her mentor, will look at it the same way.

[pause 2s]

## Things to remember

A coding lesson has steps, an editor, and a live preview. Work is saved as the youth types. Ticking every step records progress toward the badge. A project is sent with an optional note and an own-work confirmation, and then it becomes a read-only copy that waits for the mentor.
