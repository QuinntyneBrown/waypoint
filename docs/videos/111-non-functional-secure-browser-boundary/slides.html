Securing the browser boundary

Protections that work quietly between browser and server

Who may talk to Waypoint

  • The page attaches the sign-in token to each request
  • It is not a cookie the browser sends by itself
  • Other websites cannot borrow it
  • Only trusted web addresses are accepted by the server

Safety instructions on every response

  • Never shown inside another site's frame
  • Do not guess the type of a file
  • Reveal as little as possible about where the visitor came from
  • Always use a secure connection
  • A content security policy limits what may run

Rate limits on the busiest doors

  • Sign-in, password reset and invitations
  • By default, twenty requests a minute from one address
  • Too many requests, please try again later
  • Works alongside the account lock

Things to remember

  • The token is attached by the page, not by a cookie
  • Only trusted web addresses may talk to the server
  • Every response carries safety instructions
  • Sign-in, reset and invitations are rate limited
