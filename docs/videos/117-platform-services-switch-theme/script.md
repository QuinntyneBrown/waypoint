# 117 · Switching between light and dark

## Welcome

Some people like a bright screen. Others find it hard on the eyes, especially in the evening. Waypoint has two themes, light and dark, and each person chooses which one they see. This video shows how the choice works, and how it follows the person around the app.

[pause 2s]

## Following the device

Before anyone signs in, Waypoint has no preference to go on. So it follows the device. When the device is set to a light colour scheme, the sign in page is light. When the device is set to dark, the same page turns dark. Nobody has to do anything.

Every page reads its colours from one shared set of design tokens, so the whole product changes together. Even the scroll bars and form controls match.

[pause 2s]

## Choosing a theme

Meet Amara. She signs in on a laptop that is set to light, and opens her settings, and then the display tab. Under text size there is a control called theme, with three options. System, light and dark.

System is the default. It means, match my device. Right now it is selected, so Amara sees the light theme, because her laptop is light.

[pause 2s]

## A live preview

Amara chooses dark. The page changes at once. Nothing has been sent to the server yet. It is only a preview, so she can look around and decide. If she chooses system again, the page goes straight back to light.

[pause 2s]

## Saving and keeping it

The choice becomes hers when she presses, save settings. A short message appears.

The theme is saved with her other display choices, on the server. So when Amara reloads the page, it is still dark, even though her laptop is still set to light. An explicit choice of light or dark overrides the device. Only system follows it.

[pause 2s]

## Things to remember

Waypoint has a light theme and a dark theme. Signed out pages always follow the device. Each person chooses system, light or dark, and system is the default. A choice previews instantly, and it is kept once the person presses save settings. Because every colour comes from shared tokens, every page follows the choice.
