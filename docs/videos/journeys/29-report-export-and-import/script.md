# 29 · Report, export and import

## Welcome

Every program needs to answer a simple question, how are we doing? And it often needs to move data in and out. This video follows Pat Morgan, a program administrator, as Pat runs a filtered report, exports it, and then imports a roster from a spreadsheet.

[pause 2s]

## Running a report

Pat opens the reports hub. At the top is a card called report filters, with a line that says every overview and staff metric uses this exact scope. There are five filters. A date from and a date to, a cohort, a track, and a mentor.

Pat chooses one cohort, its track, and its lead mentor, Grace Adeyemi, and presses apply report filters. The hub recomputes. It shows when the report was updated and how many youth records it covers, here one. Below are six figures. Active youth, average completion, attendance, retention, cohorts, and active mentors. Every figure follows the filters Pat chose.

[pause 2s]

## Exporting what you see

At the top right are two buttons, export CSV and export PDF. Pat presses export CSV. For a moment the button says, preparing CSV. Then the file downloads, and a green message says, CSV export prepared for the current report and filters.

That message is the promise. The export covers exactly the report on the screen and exactly the filters Pat chose. A CSV gives raw rows for a spreadsheet, and a PDF gives a formatted summary. A person can only export data their role is allowed to see, and every export is written to the audit log.

[pause 2s]

## Importing a roster

Now data comes the other way. Pat opens the import roster page. Many programs already keep a roster in a spreadsheet, and Waypoint can bring it in through three reviewed steps.

Step one is upload. The page accepts a CSV file only, up to two megabytes. Pat chooses the file, called summer roster, and the page says, four rows, seven columns.

Step two is mapping. Every column is listed with a sample value and a menu for the Waypoint field it belongs to. Waypoint suggests matches, so full name becomes name. Pat sets the notes column to status, and the leader column to skip. A skipped column is simply ignored.

[pause 2s]

## Preview and confirm

Pat presses preview roster, and Waypoint checks every row. Amara Bell is ready. David Osei is a duplicate, because his email already has an account. Imani Clarke is missing consent. And one row has an email that is not an email, so it is invalid. A summary above the table counts them.

Pat presses the import button, and a confirmation says that only one ready row will create an account. Duplicates, missing consent rows, and invalid rows stay unchanged. Pat confirms, and the result says, import complete, one imported, one duplicate skipped, one needs consent, one invalid. The import is written to the audit log, and people are matched by email, so running the same file again does not create duplicates.

[pause 2s]

## Things to remember

Every report figure follows the filters. An export matches the screen exactly, and nobody can export more than their role can see. An import has three steps, upload, map, and preview. Only ready rows become accounts. Reports and imports leave a trail in the audit log.
