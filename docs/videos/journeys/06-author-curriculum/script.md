# 06 · Author curriculum

## Welcome

Before a young person can learn anything in Waypoint, someone has to write what they will learn. This video follows Pat Morgan, a program administrator, as Pat builds a curriculum from nothing. Pat creates a track, fills it with modules, writes a lesson, and publishes the lot.

[pause 2s]

## Creating a track

Pat opens the curriculum builder and presses new track. A small form asks for a track name, a track key, and a description. Pat types, servant leadership, gives it a short key, and describes it as a pathway for learning to lead by serving. Tracks are made by the program, so a Bible track, a leadership track, and a coding track can sit side by side. The key must be unique.

Pat presses create track. The new track is selected, it is marked as a draft, and the page says, no modules yet.

[pause 2s]

## Adding modules in order

Modules come next. A short form holds a module name, a description, a scripture anchor, and a module prerequisite. Pat adds foundations first, with the anchor Mark ten, forty five. Then Pat adds serving others, and chooses foundations as its prerequisite. A youth must finish foundations before serving others.

Each module has buttons to move it up and down, because the order decides what a youth sees first. Waypoint protects the prerequisites. When Pat tries to move serving others above foundations, Waypoint refuses. It says, a prerequisite must remain before its dependent module, and the order stays as it was.

[pause 2s]

## Writing a lesson

Now for the lesson itself. In the foundations module, Pat presses add lesson. The form asks for a title, a scripture reference, and the estimated minutes. Pat types, serving like Jesus, Mark ten, forty five, and twenty five minutes.

Below that are the learning objectives, and the big teaching body, which is the text the youth reads. Two smaller boxes sit side by side. Reflection prompts hold the questions a youth thinks about. Leader guide notes hold advice for the person leading the session, and those notes are never shown to a youth. So Pat can write honest, practical advice.

Pat presses create lesson, and it appears in the module as a draft.

[pause 2s]

## Publishing

Everything Pat has written is hidden until it is published. Pat presses publish lesson, and the card changes from draft to published. Pat then publishes the foundations module, and a message says, module published. Finally, Pat presses publish track, and the message says, track published.

Once a module is published, it becomes visible to the youth in the cohorts it is assigned to. Only a program administrator can edit curriculum. Anyone else is turned away.

[pause 2s]

## Things to remember

A curriculum is built from the top down. A track holds modules, and a module holds lessons. The order decides what youth see, and a prerequisite can never come after the module that needs it. Leader guide notes stay with the leaders. Nothing reaches a youth until it is published.
