# 012 · Setting a secure password

## Welcome

Every account in Waypoint is protected by a password, and the rule for a good password is the same wherever a password is chosen. This video shows that rule on screen, what the person sees when they break it, and how the password is kept safe afterward.

[pause 2s]

## The rule

Amara is choosing a new password. Under the first box, the page states the rule in plain words: use at least eight characters, including a letter and a number.

She starts with a short one, only five characters. The rule turns red, and the reset password button stays switched off. Waypoint does not let a password that is too weak go any further.

[pause 2s]

## Matching and showing

Next she types a password that follows the rule, and then types a slightly different one in the confirm box. A message appears under it that says, passwords do not match. The button stays off until the two boxes are the same.

Each box has a small eye button. Amara presses it to show the password she typed, and checks it for typing mistakes. Pressing it again hides it. This is helpful for young people typing on a phone, where mistakes are easy to make.

When the password follows the rule and both boxes match, the button turns on.

[pause 2s]

## The same rule everywhere

The rule is not special to this page. David has been invited to join as a youth. On the invitation page he creates his password, and he sees the same rule in nearly the same words, at least eight characters with a letter and a number. A password is checked in the same way whether it comes from an invitation, a reset, or a change.

[pause 2s]

## Kept safe

What happens after the password is accepted? The program never keeps the password itself. It stores only a scrambled version, made with a strong method that adds a different random value for every person. The real password is never written down, and never recorded in logs. The password boxes are also kept out of analytics.

[pause 2s]

## Things to remember

A password needs at least eight characters, with a letter and a number. The same rule applies everywhere a password is set. Both boxes must match before the button turns on. The eye button shows or hides what was typed. Only a scrambled version is stored, never the password itself.
