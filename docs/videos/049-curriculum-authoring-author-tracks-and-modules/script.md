# 049 · Authoring tracks and modules

## Welcome

Everything a young person learns in Waypoint sits inside a track, and every track is made of modules. This video shows how a program administrator creates a track, builds its modules in order, and publishes it.

[pause 2s]

## Creating a track

Pat Morgan, a program administrator, opens the curriculum builder. At the top right is a button called new track. Pat presses it.

A form asks for a track name, a track key, and a description. Pat types, servant leadership, gives it a short key, and describes it as a pathway for learning to lead by serving. Tracks are made by the program, so they are not limited to a fixed list. A Bible track, a leadership track, and a coding track can all live here side by side. The key must be unique.

Pat presses create track. The track becomes the selected one, and it shows a draft label and zero modules. Below it, a friendly message says, no modules yet.

[pause 2s]

## Adding modules

Modules come next. A short form at the top of the page holds the module name, a description, a scripture anchor, and a module prerequisite.

Pat adds the first module, foundations, with the anchor, Mark ten, forty five. Then Pat adds a second, serving others, and picks foundations as its prerequisite. That means a youth finishes foundations first. Every new module starts as a draft, and the page numbers the modules in their order.

[pause 2s]

## Putting modules in order

Each module has buttons to move it up and down, because the order decides what a youth sees first. Waypoint also protects the prerequisites. Pat adds a third module, leading well, and moves it to the top. That works. But when Pat tries to move serving others above foundations, Waypoint refuses and says, a prerequisite must remain before its dependent module. The order stays as it was.

[pause 2s]

## Publishing

A module is hidden until it is published. Pat presses publish module on foundations. A message says, module published, and its label changes from draft to published. Once a module is published, it becomes visible to the youth in the cohorts it is assigned to.

When the track is ready, Pat presses publish track. The message says, track published, and the track label changes too.

Only a program administrator can edit curriculum. Anyone else is denied.

[pause 2s]

## Things to remember

A track has a name, a unique key, and a description. Modules have a description, a scripture anchor, and an optional prerequisite. The order decides what youth see, and a prerequisite can never come after the module that needs it. Draft work stays hidden until it is published.
