# 046 · Authoring lessons

## Welcome

Lessons are the heart of the curriculum. This video follows a program administrator as they write a lesson, attach a leader guide, and publish it, and it explains which parts a youth sees and which parts only the leaders see.

[pause 2s]

## Writing the lesson

Pat Morgan, a program administrator, opens the curriculum builder and picks a track. In the module where the lesson belongs, Pat presses add lesson.

The form starts with a lesson title, and Pat types, serving like Jesus. Then come a scripture reference, Mark ten, forty five, and the estimated minutes, twenty five. Below those are learning objectives, which say what a youth should be able to do afterward.

The big box is the teaching body. This is the text the youth reads. Under it are two smaller boxes side by side. Reflection prompts hold the questions a youth thinks about, such as, who can you serve this week. Leader guide notes hold advice for the person leading the session.

[pause 2s]

## What youth never see

That last box matters. Leader guide notes are for mentors only. When the lesson is delivered to a youth, those notes are never shown. So Pat can write honest, practical advice, like, invite safe, everyday examples, knowing it stays with the leaders.

Pat presses create lesson, and the lesson appears in the module as a draft.

[pause 2s]

## Adding a file

On the lesson card there is a field called upload PDF or MP4. Pat chooses a leader guide document, and its file name appears on the card, with a button to remove it. Waypoint accepts only those two kinds of file, a document or a video, and uploads are checked for type and size.

If a file turns out to be wrong, one press removes it.

[pause 2s]

## Publishing and archiving

The card also has buttons to edit the lesson, move it up or down within the module, and publish it. Pat presses publish lesson. A message says, lesson published, and the card now reads published instead of draft. A published lesson is live for the youth in the assigned cohorts.

There is one more button, archive lesson. Archiving does not erase anyone's work. Youth progress for that lesson is kept, and any quiz linked to it stays in place.

Only a program administrator can edit lessons. Everyone else is denied.

[pause 2s]

## Things to remember

A lesson has a title, a scripture reference, a time estimate, objectives, a teaching body, reflection prompts, and leader guide notes. Leader guide notes are never shown to youth. Files must be a document or a video. A lesson reaches youth only when it is published, and archiving keeps their progress.
