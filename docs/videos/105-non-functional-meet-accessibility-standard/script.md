# 105 · Accessible to everyone

## Welcome

Not everyone uses Waypoint with a mouse and perfect eyesight. Some people use only a keyboard. Some use a screen reader. Some need larger text or stronger contrast. Waypoint is built to meet the web accessibility standard known as W C A G two point one, level double A. This video shows what that looks like in the screens you already know.

[pause 2s]

## Using only the keyboard

Amara Bell opens the sign-in page and presses the tab key. A clear outline appears around the email box, so she can see where she is. Each press of tab moves to the next control, in the order she would read them. Every field has a real label above it, and the buttons can be reached and pressed without a mouse.

When a field is wrong, the page does not rely on colour alone. The box turns red, and a sentence appears beneath it, like, enter a valid email address. A person who cannot tell red from grey still gets the message in words.

[pause 2s]

## Dialogs

Pat Morgan, a program administrator, opens the create cohort dialog. Focus moves straight into the dialog, and tab keeps cycling inside it, so a keyboard user cannot wander into the page behind. Pressing escape closes it. Focus then returns to the button that opened it, so Pat is back exactly where they started.

[pause 2s]

## Display preferences

On the display and accessibility page, anyone can adjust how Waypoint looks. They can make the text larger, in steps. They can turn on high contrast for stronger borders and text. They can reduce motion, underline every link, or switch to a reading font. The changes preview straight away, and saving keeps them for next time.

[pause 2s]

## Things to remember

Everything can be done with the keyboard, and you can always see where you are. Every field has a label, and meaning is never carried by colour alone. Dialogs keep focus inside them and give it back when they close. And each person can adjust text size, contrast and motion to suit them.
