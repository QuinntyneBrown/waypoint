# 048 · Authoring quizzes

## Welcome

A quiz checks that a lesson landed. This video shows how a program administrator builds one: the rules that govern it, the questions in it, and the correct answers that decide every score.

[pause 2s]

## Setting the rules

Pat Morgan, a program administrator, opens the curriculum builder, finds a module, and presses add quiz. The first form is about rules, not questions.

Pass mark is the score a youth needs, and Pat enters eighty. Attempts allowed is how many tries a youth gets, and Pat enters three. Feedback mode decides what a youth sees afterward. The choices are show correct answers, show score only, or after all attempts, and Pat picks after all attempts.

Two boxes follow. Shuffle questions mixes the order for each youth. Required for module completion means the module is not finished until the quiz is passed. Pat ticks both and presses create quiz.

The recorded score is the youth's best passing attempt, within the number of attempts allowed.

[pause 2s]

## A multiple choice question

A message says, quiz created, add its questions below, and a quiz editor opens. It has a form for questions.

Pat types the question text, what did Jesus say he came to do. Question type offers four kinds. Multiple choice, true or false, multiple answer, and short answer. Pat chooses multiple choice.

The answer options go in one per line. Pat lists, to be served, to serve, and to be admired. Then Pat marks the correct one by number. For choice questions the correct option is marked explicitly. Pat enters two, and presses add question.

[pause 2s]

## A short answer question

Pat adds a second question, name one way you can serve this week, and chooses short answer. The form changes. Instead of options, there is a box for correct text answers, one accepted answer on each line. Pat enters, helping at home, and, helping a neighbour.

[pause 2s]

## Order and scoring

Each question has buttons to move it up or down, and the order is saved. When shuffle is on, the order is mixed for each youth when they take the quiz.

Pat can also change the rules later with save quiz settings. And here is the important promise. When a youth takes the quiz, the score uses exactly the correct answers and pass mark that Pat saved.

[pause 2s]

## Things to remember

A quiz has rules, with a pass mark, attempts, feedback, shuffle, and whether it is required. Questions come in four types, and every correct answer is set by the author. Questions can be reordered. Scores use exactly what was saved.
