# 025 · The organization profile

## Welcome

Every program has a name, a place and a contact. This video shows how Pat Morgan, the program administrator, sets the organization's identity in Waypoint, and where that identity shows up.

[pause 2s]

## Organization identity

Pat opens Organization settings. The first panel is called Organization identity. A note under the heading says that the platform colour palette remains fixed for accessibility. So the organization can set who it is, but not how the screens are coloured, and every program keeps the same readable design.

The panel has five fields. Organization name. Display name. Logo address. City. And contact email.

Pat enters the full name of the organization, a shorter display name, and the city. Then Pat types the contact email. A note under that field explains its purpose. It is shown to guardians on consent forms and emailed records. That is why it should be an address someone actually reads.

[pause 2s]

## Saving

Pat presses Save organization settings. A green message appears at the top of the page. Organization settings saved and recorded in the audit log. Like every change to the organization settings, it is written to the audit log, and only a program administrator is allowed to make it. The server checks that on every request.

[pause 2s]

## Where it shows up

Ruth Clarke is a guardian, and she receives a consent request for her child. When she opens the secure link, the page is headed with the display name that Pat chose. It reads, Waypoint guardian consent. Beneath the participation statement is a line that begins Questions, followed by the contact email Pat entered.

So Ruth sees the organization's own name, and she knows exactly where to send a question, without anyone having to edit the form. If Pat changes the display name or the contact email next term, the next form reflects it.

[pause 2s]

## Things to remember

Identity is set in one panel. Organization name, display name, logo, city and contact email. The colour palette stays fixed for everyone. Saving is recorded in the audit log, and only a program administrator can do it. Guardians see the display name and contact email on their consent form.
