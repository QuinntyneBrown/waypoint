# 047 · Authoring the progression framework

## Welcome

Waypoint measures growth, not only completed lessons. The progression framework is the map of that growth: a short list of stages, each with the competencies a young person should show. This video shows how a program administrator builds and edits it.

[pause 2s]

## Adding a stage

Pat Morgan, a program administrator, opens the progression framework page. It keeps growth stages in order and defines the competencies mentors assess. Pat presses add stage.

A small form asks for two things, a stage name and a description. Pat types, Explorer, and describes it as, beginning the pathway and learning the habits. Pat presses save stage, and the stage appears on the page. Pat adds a second stage in the same way, called servant leader. Each stage takes its place in the order, and that order is saved.

[pause 2s]

## Adding competencies

A competency is one skill or habit that belongs to a stage. On the Explorer stage, Pat presses add competency, types, reads Scripture daily, and saves it. Then Pat adds a second one, prays with a partner. On the servant leader stage, Pat adds, leads a small group.

Each competency is tied to the stage where it was added, so a mentor looking at a youth sees the skills that belong to that part of the journey.

[pause 2s]

## Changing the order

Stages can move. Each stage has a button to move it up and a button to move it down. Pat moves servant leader up, and a green message confirms it. It says, framework order saved. The new order is kept, and the first stage and last stage can only move in the one direction that is open to them.

An edit stage button lets Pat rename a stage or change its description at any time.

[pause 2s]

## Removing a competency

If a competency no longer belongs, each one has a remove competency button. Pat removes, prays with a partner, and the page says it was removed from the active framework. The competency list for that stage updates at once.

[pause 2s]

## Why it matters

This framework is not just a list on a page. Waypoint uses it to work out each youth's current stage. It also feeds the competency assessments that mentors complete, and the program reports. So a careful framework here makes everything downstream clearer.

Only a program administrator can edit it.

[pause 2s]

## Things to remember

A stage has a name, a description, and a place in the order. Competencies belong to a stage and can be added or removed. Stages can be moved up and down, and the order is saved. The framework drives each youth's stage, mentor assessments, and reports.
