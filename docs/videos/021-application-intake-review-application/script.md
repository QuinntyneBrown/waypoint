# 021 · Reviewing an application

## Welcome

Every application that arrives through the public site ends up in one place, a queue for the program administrator. This video follows Pat Morgan, a program administrator, as Pat opens that queue and reviews an application before any decision is made. Reviewing changes nothing by itself. It gives Pat everything needed to decide well.

[pause 2s]

## The application queue

Pat opens the applications page. Its subtitle says it all. Review consent, place applicants, and keep every decision traceable. Below it is a table with one row for each application. Each row shows the applicant's name, their age, their neighbourhood, the track they are interested in, a status, and the date they applied.

Applicants under eighteen carry a small badge that says minor. The status badge tells Pat where each application stands. An application can be new, in review, needs consent, approved, or declined.

[pause 2s]

## Finding what needs attention

Pat does not have to read every row. In the top corner there is a menu called application status. Pat chooses needs consent, and the table shrinks to the applications from minors whose guardian consent is not yet recorded. Imani Clarke's application is there. Imani is fifteen, and her guardian, Ruth Clarke, submitted it. Choosing all statuses brings every application back.

If nothing matches, the page says so plainly, with a message that new applications and referrals will appear here for review.

[pause 2s]

## Opening the review

Pat presses review on Imani's row, and a review window opens. At the top, a yellow notice says guardian participation consent required. It explains that this minor cannot be approved into active participation until a valid consent record is linked.

Below the notice sits everything the applicant submitted. It shows who filled in the form, the neighbourhood, the cohort the applicant is interested in, and whether the participation and privacy acknowledgements were given. It shows the applicant's own words about why they are interested. It also shows the guardian's name, email, and phone number.

At the bottom of the window are the fields Pat uses to prepare a decision. Pat can set an interest track, choose a cohort and a mentor, and write a decision note. The decline and approve buttons sit below those fields, and the next video covers them. Only program administrators can see this queue, and Waypoint checks that on the server, not just in the browser.

[pause 2s]

## Things to remember

Every application lands in one queue. The status filter narrows the list to the ones that need attention, and minors are clearly marked. The review window shows exactly what was submitted, and whether guardian consent is still missing. Opening a review decides nothing. Only program administrators can use the queue.
