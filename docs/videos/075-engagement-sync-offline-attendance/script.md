# 075 · Recording attendance without a connection

## Welcome

Sessions do not always happen where the signal is good. A community room can have patchy internet. This video shows how Waypoint lets staff record attendance with no connection, and how the record catches up safely afterwards.

[pause 2s]

## When the connection drops

Meet Grace Adeyemi, a mentor, who is taking attendance for a session. Her connection drops. A dark banner appears across the top of the page. It says, you're offline, changes will save when you reconnect.

Grace keeps working. She presses all present, and adds a note for Amara Bell. Nothing is lost, because the page keeps working with what it already loaded.

[pause 2s]

## Saved on the device

Grace presses save attendance. Waypoint cannot reach the server, so it saves the marks on her device instead. The page says, saved offline, one attendance update waiting to sync. A small badge beside the roster says, one pending sync.

The waiting update is tied to Grace's account, and it does not store the youth's name, only the marks.

[pause 2s]

## Catching up

When the connection returns, Grace does not have to do anything. Waypoint uploads the waiting update automatically. The page says, all attendance changes synced.

Each update carries a unique key, so if the same update is sent twice, the server recognizes it and does not create a duplicate record.

[pause 2s]

## When two people edit the same session

Sometimes someone else edits the session while Grace is offline. For example, the program director may have already saved a different mark. When Grace reconnects, Waypoint does not guess, and it does not quietly overwrite anything. The page says that her changes conflict with a newer server edit, and offers her two choices: apply my changes, or keep the server attendance.

The outcome is always deliberate and the same every time, so no record is silently lost.

If Grace tries to leave the page with changes that are not saved at all, Waypoint warns her first, so she can stay or keep a local draft.

[pause 2s]

## Things to remember

Attendance can be recorded with no connection. An offline banner and a pending sync badge show what is waiting. Waiting updates upload by themselves, without duplicates. A conflict is shown clearly, and nothing is lost silently. Unsaved changes trigger a warning before you leave.
