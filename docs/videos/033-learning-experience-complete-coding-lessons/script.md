# 033 · Completing a coding lesson

## Welcome

Some lessons in Waypoint are about building something. This video follows a youth through a coding lesson, from the first step to sending the finished project to a mentor.

[pause 2s]

## The coding lesson

Amara opens a coding lesson called Build a welcome card. At the top is a self check progress bar. It starts at zero percent, and it counts checks toward a badge.

Below it she finds the steps on the left, a code editor on the right, and a live preview underneath. Step one says, add a welcome heading. She changes the code in the editor, and Waypoint saves her workspace as she goes. A short message confirms it. The preview shows the page she is building, so she sees her work as she writes it.

[pause 2s]

## Steps and the checklist

Each step has a code sample and a checkbox that she ticks when she is satisfied. After step one she moves to step two, add an introduction, and ticks that one too.

When both checks are done, the bar reaches one hundred percent and the page says that her badge is earned. If she closes the page and comes back, her code and her progress are still there, so she can finish another day.

[pause 2s]

## Sending it for review

Further down, a section called send your project for mentor review explains that her current editor code becomes the read only submitted copy. She can add a note to her mentor, and that note is optional. She ticks the box that says, this is my own work, and presses submit coding project. Waypoint asks her to confirm.

She lands on the submission status page. It shows the status, submitted, her submitted copy, her note, and a timeline that leads to under review. A coding project follows the same review path as any assignment.

[pause 2s]

## Things to remember

A coding lesson has steps, an editor, a live preview and a checklist. Her work is saved and can be resumed. Finishing the checks records progress toward a badge. Submitting sends a read only copy to the mentor, and it goes through the same review as assignments.
