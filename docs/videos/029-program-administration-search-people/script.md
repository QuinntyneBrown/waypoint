# 029 · Finding people

## Welcome

A program grows quickly, and a program administrator needs to find one person without scrolling through everyone. This video shows how Pat Morgan uses the people directory to search and filter.

[pause 2s]

## The directory

Pat opens People from the menu. The page is called People directory, and its subtitle says, Search and filter everyone in the program. At the top is a search box, a cohort list, and a row of role buttons. All roles, Youth, Mentor, Guardian, Volunteer, and Administrator.

Below them is a table. Each row shows a name, an email address, a role, a cohort, a status, and when the person was last active. The results come in pages, a page at a time, and a line at the bottom says which page Pat is on and how many people there are in all. That keeps the directory quick, even when the program is large.

[pause 2s]

## Searching

Pat types into the box that says Name or email. The table narrows as Pat types. Here, six people match. Amara Bell, David Osei, Imani Clarke, Ruth Clarke, Sam Whitfield, and Grace Adeyemi.

Pat wants to find the Clarke family. Typing the surname leaves only two rows, Imani Clarke, a youth, and Ruth Clarke, a guardian.

[pause 2s]

## Filtering

Pat now clicks the Youth button. The list drops to three people, Amara, David, and Imani. Role buttons and the cohort list work together with the search box, so Pat can ask for the youth in one cohort whose name contains a few letters. Whenever a filter changes, the list goes back to the first page, so Pat never lands on a page that no longer exists.

[pause 2s]

## When nobody matches

If nobody matches, the page does not show a blank table. It shows a message, No people found, and says that no one matches the current directory filters. Two buttons follow. Clear filters, to start again. And Invite people, because the person Pat is looking for may simply not have joined yet.

On a phone, the table turns into cards, with each field labelled, so the page never scrolls sideways.

[pause 2s]

## Things to remember

Search by name or email, and filter by role and by cohort. Results are paged. An empty result offers Clear filters and Invite people. Select a person to open their record, which is the next video.
