# 031 · The progress board

## Welcome

Programs used to track learning in a spreadsheet, one row per youth and one column per module. The progress board puts that view inside Waypoint, always up to date. This video shows how Pat Morgan, the program administrator, reads it.

[pause 2s]

## Choosing a cohort and track

Pat opens Progress board from the menu. The subtitle says, Every youth across every published module in the selected track. Two lists sit at the top. Cohort, and Track. Pat chooses a cohort and a track, and the board fills in.

A small green badge in the corner reads, Live updates on.

[pause 2s]

## Reading the board

Each row is a young person. Each module of the track is a column. A cell shows the state of that youth in that module. Done, In progress, Not started, or Not assigned. After the module columns come two more. The quiz average, and the overall percentage.

At the bottom is a row called Cohort average. It shows, column by column, how the cohort as a whole is doing. In the example, the youth has started the first module and not the second, so the overall figure is fifty percent, and the cohort average matches because there is only one youth in the cohort.

[pause 2s]

## Staying current

Now the youth finishes the last lesson of the first module. Pat does not press anything. The cell changes to Done, and the overall figure rises to one hundred percent. There is also a Refresh button, below the two lists, for anyone who wants to reload it by hand.

[pause 2s]

## Exports and empty tracks

Beside Refresh are two buttons, Export CSV and Export PDF. Each one produces a file for exactly the cohort and track that Pat has selected.

If Pat picks a track that has no published modules, the board does not show an empty grid. It says, No published modules, and suggests choosing another track or publishing curriculum content. The export buttons are greyed out, because there is nothing to export.

On a narrow screen, the board scrolls sideways inside its own frame, and the rest of the page stays put.

[pause 2s]

## Things to remember

Pick a cohort and a track. Read each cell as Done, In progress, Not started, or Not assigned, alongside quiz average, overall percentage and a cohort average row. The board updates itself, and the exports follow the selection.

That completes our tour of program administration.
